# CustomerIK logo files

Source and final logo files for the CustomerIK branding of the Flutter app.

## Final files (what the app uses)

| File | Copied to | Used for |
|---|---|---|
| `app-logo.svg` | `frontend/resources/flowy_icons/16x/app_logo.svg`, `frontend/resources/flowy_icons/40x/app_logo.svg` | Square icon mark |
| `app_icon.ico` (16, 32, 48, 256 px, built from `app-logo.svg`) | `frontend/appflowy_flutter/windows/runner/resources/app_icon.ico` | Windows .exe, taskbar and window icon |
| `app_logo_with_text_for_light_mode.svg` (green crown, dark text) | `frontend/resources/flowy_icons/40x/app_logo_with_text_light.svg` | Sidebar logo, light theme |
| `app_logo_with_text_for_dark_mode.svg` (green crown, white text) | `frontend/resources/flowy_icons/40x/app_logo_with_text_dark.svg` | Sidebar logo, dark theme |

## Original source files

- `app_logo_with_text_light_mode.svg`: original wide logo, all white (source for both sidebar logos).
- `app_logo_with_text_dark.svg`: icon only, no text (not used).

Not replaced (kept as the original AppFlowy file by choice):
- AI chat logo (`ai_chat_logo.svg`): avatar next to AI chat replies.

Brand colours: crown green `#0BC167`, dark text `#1F2329`, white text `#F3F5F4`.
